Курс «AI-Оператор Контент-Менеджера» — практический воркбук по использованию Claude Code для автоматизации работы контент-менеджера. Вы научитесь: настраивать Claude Code под свой стиль, управлять памятью и источниками, создавать витрины, строить конвейер клиентов и закрывать первые сделки.

Каждый модуль начинается с введения (заголовок 00_intro.md в папке модуля), далее идут уроки по порядку. Бонусы — отдельные готовые шаблоны.
